# NBA Basketball Manager 2026 — integrated development build

## iPhone / iOS version
This package is configured as an iOS-friendly Progressive Web App (PWA). It is not a signed native iOS `.ipa`.

1. Put the complete folder on an HTTPS web host (GitHub Pages, Netlify, or another static HTTPS host). Do not use `file://` or send only `index.html`; all files must stay together.
2. On the iPhone, open the published HTTPS address in **Safari**.
3. Tap **Share** → **Add to Home Screen** → **Add**.
4. Launch **NBA Manager** from the Home Screen. It opens in its own app-style window.
5. Keep using the same Home Screen app/browser profile so local career saves remain available. Use **Export Career Save** regularly as a backup.

The iOS build includes an Apple Home Screen icon, standalone display metadata, safe-area layout for iPhone notches, touch-sized controls, and an offline cache for the app shell. The first launch and initial cache require internet. iOS may clear website storage under device storage pressure, so exported save backups are important.

## Run
- Unzip the package.
- Open `index.html` in a desktop browser for a quick local preview.
- For PWA installation and reliable service-worker behavior, host the folder on HTTPS.
- On iPhone: open the HTTPS URL in Safari → Share → Add to Home Screen.
- On Android: open the HTTPS URL in Chrome → Install app / Add to Home screen.
- Career saves use browser local storage. Use Export Career Save regularly to create a backup JSON. Import Career accepts a previously exported JSON save.

## Implemented in this build
- 30 NBA franchises, Eastern and Western Conferences, divisions.
- 82 game days, 15 fixtures per day, 1,230 generated regular-season fixtures.
- Standings, simulated match outcomes, quarter scores and player box-score events.
- Player season averages, attributes, potential, fatigue and injury events.
- Starting-five selection and team tactics that modify simulated performance.
- Trade center with player-for-player swaps.
- Free-agent signing and contract extensions with simplified salary matching.
- Salary cap and luxury-tax reference calculations.
- AI offseason roster filling and player progression/regression.
- Play-In qualification, best-of-seven playoff series and NBA Finals.
- Awards, champion records, match archive.
- Commissioner player editing, injury toggle, trade difficulty, franchise control and unlimited funds.
- Multiple career saves, local save/load, JSON export/import.
- Responsive layout and PWA manifest/service-worker foundation.

## Critical data and simulation limitations — read before treating as complete
This is a substantially expanded playable simulation build, but it is **not yet the fully complete game specified in the project brief**.

1. **Roster data:** the bundled seed has 150 featured player entries (five per team), not full 2025–26 opening-night rosters. Some entries originate from an earlier roster snapshot and have not all been reconciled to the October 21, 2025 opening-night team lists. Player ratings/attributes are game estimates, not official NBA ratings.
2. **Schedule:** the game creates a balanced 82-round / 1,230-fixture league schedule algorithmically. It is not the exact official 2025–26 NBA fixture calendar or dates.
3. **Collective Bargaining Agreement:** cap and tax are simplified reference values. This does not implement every NBA CBA exception, apron, Bird-rights, cap hold, trade matching or contract restriction.
4. **AI:** other franchises perform limited offseason roster filling and player development. They do not yet run a complete general-manager AI with robust trades, draft strategy, contract negotiations and tactical adaptation.
5. **Competition:** the Play-In uses a simplified simulated result; playoff series are best-of-seven but do not model the full NBA calendar, home-court sequence in detail, or all tie-break rules.
6. **Basketball simulation:** scores, player stats, fatigue and injuries are generated by a probabilistic model. It is a management-game simulation, not a possession-by-possession basketball engine. Detailed team box-score totals, play-by-play and advanced analytics are not complete.
7. **Staff and finances:** coaching tactics are represented, but a complete coach/staff hiring market, full team revenue/expenses, sponsorship, arena and ownership systems are not implemented.
8. **Verification:** automated syntax and schedule QA are included. Full manual browser testing on iPhone/Android and multi-season endurance testing have not been performed here.

## Test
Install Node.js, then run:
```bash
node --check app.js
node --check database.js
node qa.js
```

The QA checks the 30-team structure and verifies exactly 82 games for every franchise across 82 game days. It intentionally does not claim the incomplete seed roster is a full NBA roster.
